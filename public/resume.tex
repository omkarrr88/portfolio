\begin{rSection}{PROJECTS}

\begin{itemize}
\item \textbf{Vehicle-to-Vehicle Communication for Blind Spot Detection and Accident Prevention Using Severity-Gated Collision Risk Indexing (May 2026):} A simulation where vehicles warn each other about blind spots and likely collisions before they happen. Built the messaging between vehicles, the sensor data processing, and a risk score that decides when to alert the driver. The work became a research paper, now under review at \textit{Discover Internet of Things} (Springer Nature). \href{https://github.com/omkarrr88/V2V}{\textit{GitHub}}

\item \textbf{Smart PUC (May 2026):} A blockchain-based system for monitoring vehicle emissions and PUC compliance in India. OBD devices sign live emission telemetry, testing stations validate it, and the records go on-chain so no single party can fake the data. Tracks all five Bharat Stage VI pollutants with physics-based models and an ML ensemble for fraud detection, and issues emission certificates as NFTs. Built with Solidity smart contracts (Hardhat, OpenZeppelin), a FastAPI/Web3.py backend, and a web dashboard. \href{https://github.com/omkarrr88/Smart_PUC}{\textit{GitHub}}

\item \textbf{Shopify Gold Price Automation System (March 2026):} End-to-end automated pricing engine for a luxury jewellery Shopify store with $\sim$939 products and 55,000+ variants. Scrapes live gold rates from IBJA twice daily, recalculates all variant prices via a component-wise formula (gold weight $\times$ purity rate + diamond weight + making charges), and pushes updates through Shopify GraphQL Bulk Operations API with zero manual steps. Deployed on Railway with Flask, PostgreSQL, and Telegram bot notifications. \textit{(Proprietary)}

\item \textbf{Invoice \& Payment Management Portal (March 2026):} Full-stack enterprise financial platform for invoice tracking, payment scheduling, and UTR verification. Features a slab-based early-payment discount engine, daily interest penalty calculations, bulk Excel invoice import, role-based access (Admin, Customer, Agent, Sub-Agent, Employee), and a payment simulator. Built with React, TypeScript, Express.js, Prisma ORM, and PostgreSQL; deployed on Railway. \textit{(Proprietary)}

\item \textbf{Face Recognition Attendance System (May 2025):} An attendance system that marks students present from a camera feed using face recognition. Built with OpenCV and the face-recognition library, with records stored in MySQL and exported as attendance reports. \href{https://github.com/omkarrr88/face-recognition-attendance-system}{\textit{GitHub}}

\item \textbf{Fitness Tracker Application (Nov 2024):} A web app for logging diet, sleep, and workouts, with a BMI calculator and goal tracking. Uses Chart.js to show progress over time. \href{https://github.com/omkarrr88/Fitness-Tracker}{\textit{GitHub}}

\item \textbf{Movie Recommendation System (May 2024):} A movie recommendation web app built on collaborative filtering. Pulls movie data from the IMDB/TMDB APIs and runs sentiment analysis on user reviews with NLTK. React frontend, Flask backend. \href{https://github.com/omkarrr88/movie-recommendation-system}{\textit{GitHub}}
